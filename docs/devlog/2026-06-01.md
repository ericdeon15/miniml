# Log for June 1, 2026

Today, I finished Chapter 3 of the CS3110 textbook. The latter half of the chapter definitely had a lot of interesting information on advanced types in Ocaml. It was especially great to read the section on algebraic data types. This section really proved how powerful variants can be for modeling complex structures in our code. Variants constructors can carry data and can be recursed on—both of these notions prove very promising for modeling things such as an AST, the fundamental model behind the structure of a language.

Recursive variants especially reminded me of BNF grammar rules, which will hopefully make it easier when it comes time to model my grammar within the code. I thought it was cool how the built-in `list` and `option` types of Ocaml are actually parameterized variants——the rules of the language were used to support and evolve the language itself.

Now, that I have learned more about the advanced types in Ocaml, I see how I can represent the basics of my AST in code and can start experimenting / implenting it. The plan is to start as basic as possible (i.e. a glorified, simple calculator) and work up from there. The actual syntax of the language will be determined later and will most likely evolve as I progress in this project——any syntax I devise will be reducible into the AST anyway (after lexing and parsing).
