# Log for May 30, 2026

Today, I read part of Chapter 3 of the texbook from Cornel CS3110. An interesting thing I learned was actually something that was on my mind. Since lists are immutable in Ocaml, I was concerned about the memory consumption from applying functions. However, Ocaml doesn't create new memory equivalent to the size of the tail (for example, in pattern matching h::t), but shares that memory with the list passed from the callee.

It was also great to learn more about the different data types that Ocaml offers, such as variants and records. Vairants allow us to define new variables of the variant type and assign one of the constructor, or vairant values, to said variable. To me, they seem very much like unions in C, but I wonder how truly similar or dissimilar they are. Records allow us to create new "objects" of a type that are defined by the product of all of its fields. They are very alike structs in C. Both variants and records seem like they will be very useful for the MiniML project, as I utilized both unions and structs for the compiler I made written in C.
