# Chapter 1: Starting Off

## Key Ideas

- Ocaml is strongly, staitcally typed.

## Important syntax

Operators:

- / : Integer division
- mod : Modulus
- = : == like in Python
- <> : != like in Python

if-else statement:

```ocaml
if 1 > 0 then "yes!" else "no!";;
```

## Things I Learned

- Ocaml doesn't do implicit type casting—it is strongly, statically typed
- Ocaml has a `char` type for single characters

## Things That Confused Me

- I am curious how the parsing for `=` works for a variables versus a boolean condition. The `let` keyword most likely determines this distinction in the grammar

## MiniML Connection
